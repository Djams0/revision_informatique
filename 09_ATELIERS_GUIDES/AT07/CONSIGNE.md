# AT07 — Déboguer une erreur de logique (S12)

**Durée : 20–40 minutes.** Lis d'abord le cours correspondant dans 01_COURS. **Situation :** Le programme doit compter les notes >= 10, mais la condition actuelle oublie une valeur limite. Prévoir les sorties, exécuter puis corriger un seul symbole.

1. Copie [CODE_A_CORRIGER.py](CODE_A_CORRIGER.py) dans ton dossier personnel mes_exercices/S12.
2. Complète les zones TODO ou [COMPLETER] sans lire la correction.
3. Note au moins deux résultats **attendus** avant toute exécution.
4. Ouvre le .py dans Thonny, exécute, compare attendu / observé. Si nécessaire, reprends la logique.
5. Explique l'étape qui fait la différence, puis compare avec [la correction détaillée](../CORRIGES/AT07.md).

**Jeux d'essai :** [9,10,12] → 2 ; [10] → 1 ; [] → 0.

**Question de vérification :** explique à voix haute, en trois phrases, pourquoi la méthode fonctionne. Si tu ne peux pas encore, reprends le plus petit cas.
