# AT06 — Fonction dans les deux sens (S11)

**Durée : 20–40 minutes.** Lis d'abord le cours correspondant dans 01_COURS. **Situation :** Traduire « FONCTION double(nombre) RETOURNER nombre*2 » vers Python puis reformuler le Python final en pseudo-code. Distinguer return de print.

1. Copie [A_COMPLETER.py](A_COMPLETER.py) dans ton dossier personnel mes_exercices/S11.
2. Complète les zones TODO ou [COMPLETER] sans lire la correction.
3. Note au moins deux résultats **attendus** avant toute exécution.
4. Ouvre le .py dans Thonny, exécute, compare attendu / observé. Si nécessaire, reprends la logique.
5. Explique l'étape qui fait la différence, puis compare avec [la correction détaillée](../CORRIGES/AT06.md).

**Jeux d'essai :** 4 → 8 ; 0 → 0 ; -3 → -6.

**Question de vérification :** explique à voix haute, en trois phrases, pourquoi la méthode fonctionne. Si tu ne peux pas encore, reprends le plus petit cas.
