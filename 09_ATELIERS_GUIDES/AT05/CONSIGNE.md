# AT05 — Traduire Python vers pseudo-code (S9)

**Durée : 20–40 minutes.** Lis d'abord le cours correspondant dans 01_COURS. **Situation :** Lire le code Python fourni, prédire sa sortie, puis réécrire sa logique en pseudo-code en respectant les bornes des boucles.

1. Copie [A_COMPLETER.txt](A_COMPLETER.txt) dans ton dossier personnel mes_exercices/S9.
2. Complète les zones TODO ou [COMPLETER] sans lire la correction.
3. Note au moins deux résultats **attendus** avant toute exécution.
4. Ouvre le .py dans Thonny, exécute, compare attendu / observé. Si nécessaire, reprends la logique.
5. Explique l'étape qui fait la différence, puis compare avec [la correction détaillée](../CORRIGES/AT05.md).

**Jeux d'essai :** for nombre in range(1,4) puis print(nombre * 2) → 2, 4, 6. Pas de 8.

**Question de vérification :** explique à voix haute, en trois phrases, pourquoi la méthode fonctionne. Si tu ne peux pas encore, reprends le plus petit cas.
