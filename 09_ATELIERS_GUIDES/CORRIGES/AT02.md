# AT02 — Correction expliquée

**Une solution de référence** (d'autres solutions correctes sont possibles) :

~~~text
LIRE age
SI age < 0 ALORS
  AFFICHER "Âge invalide"
SINON SI age >= 18 ALORS
  AFFICHER "Autorisé"
SINON
  AFFICHER "Refusé"
FIN SI
~~~

**Pourquoi :** Tester les entrées invalides en premier évite les cas absurdes. >= inclut la frontière 18 ; > exclurait 18. L'ordre des conditions et les résultats attendus sont essentiels.

**Résultats à comparer :** -1 → Âge invalide ; 17 → Refusé ; 18 → Autorisé ; 25 → Autorisé.

**À refaire sans copier :** changer un nombre ou un cas limite, prévoir la sortie, puis vérifier.
