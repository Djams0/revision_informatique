# AT07 — Correction expliquée

**Une solution de référence** (d'autres solutions correctes sont possibles) :

~~~python
def compter_notes_valides(notes):
    total = 0
    for note in notes:
        if note >= 10:
            total += 1
    return total

print(compter_notes_valides([9, 10, 12]))
~~~

**Pourquoi :** Ce programme compile, mais > exclut 10. Il faut >=. Tester exactement 10 révèle le problème ; vérifier aussi la liste vide. Une erreur de logique n'est pas une erreur de syntaxe.

**Résultats à comparer :** [9,10,12] → 2 ; [10] → 1 ; [] → 0.

**À refaire sans copier :** changer un nombre ou un cas limite, prévoir la sortie, puis vérifier.
