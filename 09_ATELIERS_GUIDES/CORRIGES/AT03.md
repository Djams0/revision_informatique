# AT03 — Correction expliquée

**Une solution de référence** (d'autres solutions correctes sont possibles) :

~~~text
LIRE n
SI n < 0 ALORS
  AFFICHER "Invalide"
SINON
  total ← 0
  POUR i DE 1 À n FAIRE
    total ← total + i
  FIN POUR
  AFFICHER total
FIN SI
~~~

**Pourquoi :** total commence à 0, puis accumule 1, 2, 3. Notre pseudo-code inclut n dans POUR i DE 1 À n. En Python il faudra range(1, n+1) car la dernière borne est exclue.

**Résultats à comparer :** n=3 → total 1, 3, 6 ; n=0 → 0 ; n=1 → 1 ; n négatif → Invalide.

**À refaire sans copier :** changer un nombre ou un cas limite, prévoir la sortie, puis vérifier.
