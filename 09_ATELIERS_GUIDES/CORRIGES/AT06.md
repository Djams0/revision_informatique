# AT06 — Correction expliquée

**Une solution de référence** (d'autres solutions correctes sont possibles) :

~~~python
def double(nombre):
    return nombre * 2

valeur = int(input("Entier ? "))
resultat = double(valeur)
print(resultat)
~~~

**Pourquoi :** return donne une valeur à l'instruction appelante ; print l'affiche. Le paramètre nombre reçoit la valeur de l'appel. Écrire l'équivalent en pseudo-code : FONCTION double(nombre) / RETOURNER nombre * 2 / FIN FONCTION / LIRE valeur / resultat ← double(valeur) / AFFICHER resultat.

**Résultats à comparer :** 4 → 8 ; 0 → 0 ; -3 → -6.

**À refaire sans copier :** changer un nombre ou un cas limite, prévoir la sortie, puis vérifier.
