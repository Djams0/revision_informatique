# P4 — Page portfolio locale — critères et tests

## Acceptation

- [ ] HTML avec langue, titre, `main`, sections et titres hiérarchisés.
- [ ] Lien interne fonctionnel et projet décrit clairement.
- [ ] CSS séparé et page lisible sans CSS.
- [ ] README autonome, aucune donnée privée ni dépendance réseau.

## Trois tests minimum

1. Double-clic sur index.html → contenu visible hors ligne.
2. Clic « Voir mes projets » → section projets atteinte.
3. Fenêtre étroite → texte lisible, sans débordement horizontal.

**Validation :** noter attendu, observé et éventuelle correction pour chacun ; une autre personne peut suivre le README sans explication orale.
