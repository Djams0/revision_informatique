# Solution de référence — P4 — Page portfolio locale

Le HTML structure un contenu compréhensible sans mise en forme. Le CSS limite la largeur et règle contrastes/espaces ; le lien interne fonctionne dans un fichier local. Le README explique à une autre personne comment ouvrir la page.

## Lancement et tests

- Double-clic sur index.html → contenu visible hors ligne.
- Clic « Voir mes projets » → section projets atteinte.
- Fenêtre étroite → texte lisible, sans débordement horizontal.

Les données sont fictives ; tester sur une copie locale. Cette solution est un exemple lisible, pas la seule réponse possible.
