# P3 — Liste de tâches locales — critères et tests

## Acceptation

- [ ] Dossier neuf fonctionnel sans `FileNotFoundError`.
- [ ] Les données survivent à un deuxième lancement.
- [ ] Entrée vide ou menu inconnu ne plante pas.
- [ ] Utilisation locale et instructions de lancement dans README.

## Trois tests minimum

1. Nouveau dossier, choix 1 → Aucune tâche.
2. Choix 2, « Lire », puis 1 → Lire affiché.
3. Relancer et choix 1 → Lire encore affiché ; choix 2, vide → refus.

**Validation :** noter attendu, observé et éventuelle correction pour chacun ; une autre personne peut suivre le README sans explication orale.
