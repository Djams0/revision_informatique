# Solution de référence — P3 — Liste de tâches locales

La lecture renvoie `[]` si aucun fichier n’existe. L’ajout utilise `a` afin de préserver les lignes précédentes. Le menu relit le fichier lorsqu’on choisit Voir ; la boucle se termine avec 0. Le fichier reste dans le dossier de l’exemple.

## Lancement et tests

- Nouveau dossier, choix 1 → Aucune tâche.
- Choix 2, « Lire », puis 1 → Lire affiché.
- Relancer et choix 1 → Lire encore affiché ; choix 2, vide → refus.

Les données sont fictives ; tester sur une copie locale. Cette solution est un exemple lisible, pas la seule réponse possible.
