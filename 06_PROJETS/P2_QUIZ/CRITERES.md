# P2 — Quiz interactif Python — critères et tests

## Acceptation

- [ ] Trois questions posées une fois chacune.
- [ ] Score entre 0 et 3 et correction de casse/espaces.
- [ ] Une réponse invalide ne plante pas.
- [ ] README explique les réponses attendues sans révéler les solutions avant la partie.

## Trois tests minimum

1. a,b,a → 3/3
2. b,b,b → 1/3
3.  A , B , a → 3/3

**Validation :** noter attendu, observé et éventuelle correction pour chacun ; une autre personne peut suivre le README sans explication orale.
