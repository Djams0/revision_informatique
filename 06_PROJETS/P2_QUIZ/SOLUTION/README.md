# Solution de référence — P2 — Quiz interactif Python

La liste porte les trois questions et bonnes réponses ; la boucle en pose une à chaque tour. La fonction conserve un score local, l’incrémente seulement à l’égalité puis le retourne. La saisie est normalisée ; une autre lettre est simplement fausse.

## Lancement et tests

- a,b,a → 3/3
- b,b,b → 1/3
-  A , B , a → 3/3

Les données sont fictives ; tester sur une copie locale. Cette solution est un exemple lisible, pas la seule réponse possible.
