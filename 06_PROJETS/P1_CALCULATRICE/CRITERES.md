# P1 — Mini-calculatrice en console — critères et tests

## Acceptation

- [ ] Fonction distincte de la saisie, retour utilisé par l’appelant.
- [ ] Trois opérations produisent les résultats attendus.
- [ ] Choix inconnu affiche un message sans plantage.
- [ ] README permet un lancement local sans compte.

## Trois tests minimum

1. 2,3,+ → 5
2. 8,5,- → 3
3. 4,-2,* → -8 ; opération / → choix inconnu

**Validation :** noter attendu, observé et éventuelle correction pour chacun ; une autre personne peut suivre le README sans explication orale.
