# Solution de référence — P1 — Mini-calculatrice en console

La fonction sélectionne une branche et retourne une valeur ; `None` signale uniquement une opération inconnue. La saisie est convertie hors de la fonction ; un `ValueError` affiche une indication. Le résultat zéro reste valide.

## Lancement et tests

- 2,3,+ → 5
- 8,5,- → 3
- 4,-2,* → -8 ; opération / → choix inconnu

Les données sont fictives ; tester sur une copie locale. Cette solution est un exemple lisible, pas la seule réponse possible.
