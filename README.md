# Formation informatique débutante — 18 semaines

Une formation autonome pour une personne adulte qui part de zéro. Elle commence par les fichiers, les logiciels et Internet, puis passe par le pseudo-code avant de programmer en **Python 3**. Elle se termine par des bases de HTML/CSS, de SQL, du terminal et de Git, puis un projet personnel.

**Rythme :** environ 3 à 5 heures par semaine pendant 18 semaines, à adapter librement. **Matériel :** un ordinateur Windows, macOS ou Linux et un navigateur. Les cours et les exercices sont gratuits ; un compte GitHub est facultatif pour apprendre.

## Par où commencer ?

1. Ouvre le [mode d'emploi](README_COMMENCER_ICI.md). Il explique comment organiser tes fichiers, choisir tes exercices et travailler même si tu n'as jamais programmé.
2. Consulte l'[index des 18 semaines](INDEX.md), puis lis [M00 — premiers pas avec l'ordinateur](01_COURS/M00.md).
3. Chaque semaine, reproduis les exemples, essaie les [exercices](03_EXERCICES/) et remplis le [tableau de suivi](SUIVI_18_SEMAINES.csv). Ouvre les [corrigés](04_CORRIGES/) **après** ton essai.
4. Utilise les [fiches pratiques](02_FICHES/) si une notion ou une installation bloque. Les [ressources externes](07_RESSOURCES/SITES_ET_VIDEOS_VERIFIES.md) sont complémentaires.

Tu peux lire directement les fichiers Markdown (`.md`) sur GitHub. Pour les utiliser hors ligne, clique sur **Code → Download ZIP** sur la page du dépôt, puis décompresse le dossier sur ton ordinateur. Le [guide complet](GUIDE_COMPLET.md) rassemble les cours dans un document unique.
