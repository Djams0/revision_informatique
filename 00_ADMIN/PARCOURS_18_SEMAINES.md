# Parcours principal de 18 semaines

Public : adulte francophone débutante absolue. Charge cible : **4 h par semaine**, ajustable de 3 à 5 h, soit environ 72 h. Chaque semaine : 60–90 min de cours guidé, 90–120 min de pratique, 30–60 min de correction et bilan. Les tâches essentielles tiennent en 3 h ; une variante facultative ajoute jusqu'à 2 h. Les contrôles sont des actions observables, sans note punitive. Un ordinateur Windows, macOS ou Linux, un navigateur et l'installation gratuite de Thonny/Python 3 à partir de la semaine 7 suffisent. Les données restent locales. Aucun compte en ligne n'est indispensable avant l'option GitHub. Répartition harmonisée avec les neuf modules rédigés à l'étape 2 : M00=S1, M01=S2–S3, M02=S4–S6, M03=S7–S11, M04=S12, M05=S13–S14, M06=S15, M07=S16, M08=S17–S18.

## Seuils de passage et rythme

- S1–S3 : refaire les manipulations à l'écran. S4–S6 : écrire et tracer du pseudo-code **avant** sa syntaxe Python en S7–S9 ; la même situation est reprise des deux côtés.
- S11–S12 : construire deux petits programmes avant d'ajouter Web et SQL. HTML/CSS est un aperçu de technologies Web, sans JavaScript ni PHP. SQL est pratiqué sur une petite base locale, sans serveur.
- S16 : GitHub Skills nécessite un compte uniquement si l'option en ligne est choisie. Git local reste suffisant ; expliquer les commandes selon Windows/macOS/Linux dans les cours à produire.
- S17–S18 : un projet Python au choix, sans API, framework, Docker, cloud payant ou POO avancée. La page HTML/CSS et la mini-base SQLite peuvent être des annexes facultatives ; aucune intégration complexe n'est exigée.
- Si une semaine prend plus de temps, la dédoubler et déplacer la suite : le parcours conserve 18 unités pédagogiques sans imposer 18 semaines calendaires strictes. Scratch (une seule séance facultative de 45–60 min en S6) n'est requis nulle part.
