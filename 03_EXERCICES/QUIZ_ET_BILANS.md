# Quatre jalons de compréhension

Fais-les sans corrigé, en 30–40 min. Chaque jalon vaut **20 points** : quatre questions de 5 points. Pour une question, 3 points pour une réponse correcte, 2 points pour une explication ou démonstration. **16–20 :** continuer. **12–15 :** revoir les erreurs et refaire un exemple. **0–11 :** reprendre la semaine concernée avant d'empiler de nouvelles notions. Ce seuil aide à apprendre, ce n'est pas un examen officiel. Les solutions sont dans `04_CORRIGES/CORRIGES_QUIZ.md`.

## J03 — fin de semaine 3 : ordinateur, Web, sécurité

1. Un document non enregistré disparaît après une coupure : cite le rôle de la RAM et du stockage. (5)
2. Dessine « navigateur → réseau → serveur → réponse » et explique la différence entre Internet et le Web. (5)
3. Dans `https://exemple.org/livres`, repère protocole, domaine et chemin ; explique ce que fait le DNS. (5)
4. Message fictif : « Vérifie ton compte dans 5 minutes via ce lien, indique ton mot de passe ». Donne deux indices suspects et l'action sûre. (5)

## J06 — fin de semaine 6 : logique sans machine

1. Trace `x ← 2 ; x ← x + 3 ; AFFICHER x` et donne la sortie. (5)
2. Pour « 18 à 25 inclus », écris la condition en pseudo-code et teste 17, 18, 25, 26. (5)
3. Trace `total ← 0 ; POUR i DE 1 À 3 FAIRE total ← total + i FIN POUR` et note les trois valeurs de `total`. (5)
4. Pour `[4,7]`, donne longueur, premier et dernier indice ; explique comment éviter une boucle TANT QUE infinie. (5)

## J12 — fin de semaine 12 : Python, tests et fichiers

1. Prédis `int("4") + 2` puis `"4" + "2"`. Pourquoi diffèrent-ils ? (5)
2. Écris un programme Python complet qui lit un entier et affiche « pair » ou « impair ». Donne deux tests. (5)
3. Explique `range(1,4)` et le rôle de l'indentation dans `for` ; montre la sortie de trois tours. (5)
4. Une fonction reçoit `[]` pour calculer une moyenne ; quel risque ? Compare `return` et `print`. Explique aussi ce que le mode fichier `w` ferait à un ancien contenu. (5)

## J18 — fin de semaine 18 : réutiliser les acquis

1. Montre ton projet : explique entrées, sorties et un cas limite testé. (5)
2. Sur ta page locale, repère une balise HTML, un sélecteur CSS et explique le rôle de chacun ; si tu n'as pas fait de page, utilise M05. (5)
3. Dans une table `livres(id,titre)`, écris une requête SQLite qui lit les titres triés ; distingue SQL et SQLite. (5)
4. Montre deux versions locales Git ou explique les étapes `status → add → commit`. Présente une amélioration réalisable et la première vérification. (5)

**Bilan après chaque jalon :** note ton score, une chose maîtrisée, un blocage précis et la prochaine action dans `SUIVI_18_SEMAINES.csv`. Tu peux refaire le jalon avec de nouveaux exemples après révision.
