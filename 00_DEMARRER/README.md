# Bienvenue — ton point de départ

**Tu n'as jamais fait d'informatique ? Tu n'as besoin que d'un ordinateur, de temps et de curiosité.** Il ne faut PAS ouvrir tous les fichiers.

## Trois gestes pour commencer
1. Lis [la préparation du PC](INSTALLATIONS.md). Semaines 1–6 : aucun logiciel de programmation à installer.
2. Télécharge le dépôt depuis GitHub avec **Code → Download ZIP**, décompresse-le, et crée **mes_exercices** à côté du dossier de formation.
3. Ouvre [M00](../01_COURS/M00.md), fais son exemple puis [T01](../03_EXERCICES/ATELIERS_SYSTEME_RESEAU_GIT.md). Note tes progrès dans [SUIVI_18_SEMAINES.csv](../SUIVI_18_SEMAINES.csv).

## Comment apprendre une notion ?
- **15–20 min :** lire le cours ; regarder au maximum une vidéo utile ([sélection par semaine](VIDEOS_PAR_SEMAINE.md)).
- **15 min :** reproduire l'exemple en comprenant chaque étape.
- **20–40 min :** faire un exercice sans solution, écrire le résultat attendu puis observer.
- **10 min :** comparer avec la correction ; refaire un cas différent sans copier.

## Dossier de travail
- **.md** : consignes et explications, lisibles directement dans GitHub ou dans un éditeur de texte.
- **.txt** : une feuille à compléter, surtout pour le pseudo-code ; pas de logiciel spécifique.
- **.py** : programme Python à compléter et à exécuter dans **Thonny**, à partir de la semaine 7.
- **CORRIGES** : réponses expliquées, à consulter après un essai sérieux.

**Parcours recommandé :** S1–3 M00/M01 → S4–6 M02 et ateliers AT01–AT03 → S7–12 M03/M04 et AT04–AT07 → S13–16 Web, SQLite et Git → S17–18 projet final. Les [ateliers guidés](../09_ATELIERS_GUIDES/README.md) sont facultatifs mais conseillés si la logique te semble difficile.

Une semaine peut durer deux semaines. Une vidéo n'est jamais nécessaire pour réussir l'exercice local. En cas de blocage, note : **ce que j'attendais, ce qui s'est produit, ce que j'ai essayé** ; puis demande un indice à une IA.
