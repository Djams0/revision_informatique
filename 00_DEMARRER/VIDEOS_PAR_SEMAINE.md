# Une ressource utile par étape, puis pratiquer

Ces références ont été repérées sur leurs pages publiques en novembre 2026. **Lecture intégrale, sous-titres et boutons de chaque vidéo non testés** ; certains sites changent ou demandent un compte. Les vidéos complètent les cours du dépôt, elles ne les remplacent pas.

| Quand ? | Ressource | Type | Regarder / lire uniquement | Pratique immédiatement après |
|---|---|---|---|---|
| S1 | [Premiers pas sur ordinateur](https://openclassrooms.com/fr/courses/5737801-faites-vos-premiers-pas-sur-ordinateur) | FR cours/médias | Fichiers, logiciels, dossiers | Créer, retrouver bonjour.txt |
| S2–3 | [Comprendre le Web](https://openclassrooms.com/fr/courses/1946386-comprendre-le-web) | FR cours/médias | Internet/Web, client/serveur | Dessiner le trajet d'une page |
| S4–6 | [Fonctionnement des algorithmes](https://openclassrooms.com/fr/courses/7527306-decouvrez-le-fonctionnement-des-algorithmes) | FR cours/médias | Partie 1, variables, conditions, boucles | AT01, AT02, AT03 |
| S6 option | [CS50 Scratch](https://cs50.harvard.edu/scratch/weeks/1/) | EN, vidéo intégrée | Court passage sur les instructions | Décrire une procédure sans coder |
| S7 installation | [Installer Thonny](https://www.youtube.com/watch?v=U9_z6qHYsa8) | FR, vidéo 2020 | Installation, **pas un lien de téléchargement** | Exécuter bonjour.py |
| S7–11 | [Bases du langage Python](https://openclassrooms.com/fr/courses/7168871-apprenez-les-bases-du-langage-python) | FR cours/médias | Parties 1–2 seulement | AT04–AT06 et P01–P21 |

| S13–14 | [MDN — premier site](https://developer.mozilla.org/fr/docs/Learn_web_development/Getting_started/Your_first_website) | FR tutoriel | HTML/CSS, pas JavaScript | Créer index.html + style.css |
| S15 | [CS50 SQL](https://cs50.harvard.edu/sql/weeks/0/) | EN vidéo intégrée | Extrait SELECT | Essai Q01 local |

**Méthode anti-surcharge :** regarder 10 à 20 minutes, interrompre, faire l'exercice, puis revenir seulement si nécessaire. Si la vidéo présente un outil différent (VS Code plutôt que Thonny), suivre le cours local. Une vidéo ancienne peut illustrer le raisonnement mais **les logiciels ne se téléchargent que sur les sites officiels**.
